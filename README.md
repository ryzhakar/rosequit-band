# rosequit.band

Сайт сам читає два текстові файли й малює з них сторінку.

**`page_content.yaml`** — що на сторінці: альбом угорі, пісні нижче. Кожна пісня — такий блок:

```yaml
  - title: Назва пісні
    release_year: 2026
    listen_link: https://open.spotify.com/track/...
    optional_lyric_video_link: https://www.youtube.com/watch?v=...
```

- Нова пісня: скопіюйте цілий блок, вставте поруч, змініть значення. Порядок не важливий — новіші сайт ставить угору сам.
- Поля з `optional_` можна видалити разом з рядком. Решта обов'язкові: без них пісня на сайті не з'явиться.
- Обкладинку сайт бере зі Spotify сам. Для цього `listen_link` має бути посиланням зі Spotify.
- Посилання можна вставляти як є, з усіма хвостами. Сайт проводить їх через song.link (сторінка вибору сервісу).

**`interface_text.yaml`** — слова на кнопках і заголовках. Під кожним місцем стоїть `ukrainian` і `english`. Змінюйте лише текст після двокрапки.

## Правила

- Відступи — пробіли, не Tab. Дефіси й двокрапки на початку рядків не чіпайте.
- Текст із двокрапкою візьміть у лапки: `title: "Назва: друга частина"`.
- Якщо у файлі помилка, замість сторінки лишиться кнопка «Слухати на Spotify». Поверніть попередню версію файлу в історії змін.

## Решта

`index.html` — каркас, `style.css` — вигляд, `app.js` — логіка, `logo.png`, `icon.png`, `social_preview.jpg` — картинки (остання з'являється, коли ділишся посиланням), `fanzine-001/` — адреса з QR у фензині, `CNAME` — домен, `vendor/` — читач YAML. Їх не редагуйте. Якщо щось зламалось чи треба змінити вигляд — опишіть це Claude і дайте йому цей репозиторій.
